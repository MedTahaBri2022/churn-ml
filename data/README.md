# Data

`raw/telco_churn.csv` is the public **Telco Customer Churn** sample dataset
published by IBM (7,043 customers of a fictional telecom operator, 21 columns).

Source: <https://github.com/IBM/telco-customer-churn-on-icp4d>
(file `data/Telco-Customer-Churn.csv`), distributed under the Apache License 2.0.
The file is included unmodified so that training is reproducible offline and in CI.
